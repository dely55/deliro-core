# DELIRO (DEL)

### Don't trust the founder. Verify the rules.

Deliro is an independent, open-source cryptocurrency project under development.

Our goal is to build a decentralized peer-to-peer network with transparent monetary rules and independently verifiable consensus.

## Core Principles

- No premine.
- No founder allocation.
- No hidden coin creation.
- No centralized control over user funds.
- Public and auditable source code.
- Independent full-node verification.
