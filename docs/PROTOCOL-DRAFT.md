# DELIRO (DEL) — Protocol Draft

Version: 0.1
Status: Draft — Not Active

## 1. Project Overview

Deliro is a proposed independent, open-source cryptocurrency.

Its goal is to operate through transparent rules, public verification, and decentralized participation.

The network must not depend on trust in its founder.

## 2. Core Principles

- No premine.
- No founder allocation.
- No hidden coin creation.
- No central authority with unilateral control.
- All consensus rules must be public.
- Anyone must be able to inspect and verify the source code.
- Changes to consensus rules require transparent development and broad network adoption.

## 3. Proposed Network Parameters

- Name: Deliro
- Ticker: DEL
- Maximum supply target: 8,000,000 DEL
- Target block time: 10 minutes
- Proof of Work: SHA-256d
- Planned mining method: AuxPoW merged mining
- Planned halving interval: 210,000 blocks
- Decimal precision: 8 places

These parameters are proposals and are not active consensus rules.

## 4. Mining and Coin Creation

All DEL coins are intended to enter circulation through valid mining rewards.

There will be no premine or founder allocation.

The exact block subsidy schedule and integer rounding rules must be formally specified and tested before launch.

No tail emission is currently planned.

## 5. AuxPoW Merged Mining

Deliro plans to support SHA-256d AuxPoW merged mining.

Bitcoin miners and pools would need explicit support for Deliro and must submit valid auxiliary proof-of-work data.

Merged mining does not automatically give Deliro the full security or hashrate of Bitcoin.

## 6. Decentralization

The project aims to allow independent node operators to verify blocks and transactions.

No website administrator or founder account may have special authority over consensus, balances, or coin creation.

## 7. Security Requirements

Before launch, the project requires:

- A complete consensus specification.
- Independent code review.
- Mining and difficulty adjustment tests.
- AuxPoW validation tests.
- Network attack and failure testing.
- Independent security review.

## 8. Transparency

All protocol code and consensus changes must be publicly reviewable.

The project principle is:

"Don't trust the founder. Verify the rules."

## 9. Launch Status

Deliro is currently a development project.

No live blockchain, active mining network, or circulating DEL coins are claimed to exist.

A public launch will only be considered after implementation, testing, and security review.

## 10. Governance

No founder or administrator will have unilateral power to change consensus rules.

Any proposed protocol change must be publicly documented and independently reviewed.
