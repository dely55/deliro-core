# DELIRO — Development Roadmap

Version: 0.1
Status: Proposed — Development Not Started

## Phase 1 — Protocol Specification

- Finalize monetary policy.
- Specify exact consensus rules.
- Define block and transaction formats.
- Define difficulty adjustment.
- Finalize AuxPoW validation rules.
- Define network parameters.

## Phase 2 — Core Software

- Select a suitable open-source codebase.
- Implement Deliro consensus rules.
- Implement block validation.
- Implement transaction validation.
- Implement UTXO management.
- Implement peer-to-peer networking.

## Phase 3 — Testing

- Unit testing.
- Integration testing.
- Consensus testing.
- Mining simulation.
- Network attack simulation.
- Independent code review.

## Phase 4 — Testnet

- Launch a public test network.
- Invite independent node operators.
- Test mining and transactions.
- Fix discovered vulnerabilities.
- Publish test results.

## Phase 5 — Security Review

- Independent security audit.
- AuxPoW review.
- Supply verification.
- Reproducible build verification.
- Resolve critical vulnerabilities.

## Phase 6 — Mainnet Preparation

- Publish final source code.
- Publish genesis block parameters.
- Publish official binaries.
- Publish node operation instructions.
- Publish network monitoring tools.

## Phase 7 — Public Launch

Mainnet launch will only be considered after all critical requirements are completed.

No premine or founder allocation is permitted.

## Current Status

Deliro is currently in the documentation and specification stage.

No operational blockchain or mining network is claimed to exist.

## Core Principle

Don't trust the founder. Verify the rules.
